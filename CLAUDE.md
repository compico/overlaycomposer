# Правила работы в репозитории

Репозиторий `compico/overlaycomposer`, основная ветка `dev`. Общение — по-русски.

## Работаем через issue
- Вся информация о задаче хранится в issue: что и зачем, решения, ограничения, что осталось.
- Если просят то, чего нет в issue, сначала заводим issue, потом делаем.
- Номер issue есть в каждом сообщении коммита (`#N`, итоговая строка `Closes #N` или `Refs #N`), по возможности и в названии ветки: `тип/N-кратко`.

## Ветки и PR
- Ветка от `dev`, PR в `dev`. Стопок из PR нет: каждый PR самодостаточен.
- Перед пушем в существующую ветку проверь, не смержен ли её PR (`gh api repos/compico/overlaycomposer/pulls?head=compico:<ветка>&state=all`). Если смержен, начинай новую ветку от `dev`.
- Workflow `Auto PR` сам открывает PR при пуше ветки; перед ручным созданием PR проверь, нет ли уже открытого, и дополни его тело (`Closes #N`).
- Не ждём результатов CI: если он упал, разработчик пришлёт ошибки.
