Plugin store
Plugins are code written by other people. They run in a sandbox and get only the permissions you allow, but still install them only from authors you trust — you are responsible for the sources you add.
Private repositories (GitHub token)
Create a fine-grained personal access token at github.com/settings/personal-access-tokens: only the repositories you need, permission Contents: Read-only. The token is stored encrypted on this computer, is sent only to GitHub and is never shown again or given to plugins.
Copy to layout
A linked copy is the same widget in another place: when the scene changes it is moved, not reloaded, so alerts and chats keep their state. Untick to get an independent widget (it reloads on every switch).
