# Экспорт и импорт настроек

Настройки OC можно сохранить одним файлом `oc-settings.json` и перенести на другой компьютер (основа синхронизации с облаком, #98). Секреты в файл не попадают: токены Twitch,
пароли, ключи, устройства, токен магазина.

## Формат
```json
{ "format": 1, "app": "0.12.0", "createdAt": "2026-11-20T09:00:00Z",
  "sections": { "layouts": { … } }, "checksums": { "layouts": "<sha256 компактной записи секции>" } }
```
- Секции независимы: экспортировать и импортировать можно любую.
- Контрольные суммы ловят порчу и ручную правку (это не подпись); переформатирование файла им не мешает.
- Файл новее известного формата отклоняется с просьбой обновить OC; секция, которой эта версия не знает, пропускается (в плане она показана как неизвестная).
- Предел размера — 6 МБ.

## API (только с этого компьютера)
- `GET /api/settings/export?sections=a,b[&download=1]` — файл (пусто — все секции).
- `POST /api/settings/import/plan` (тело — файл) — проверка и план по секциям: у каждого элемента статус `new` / `replace` / `same` / `problem` (+ причина). Ничего не меняет.
- `POST /api/settings/import/apply` `{file, selection: {секция: {id: "replace" | "copy"}}}` — применяет выбранное. Выбрать можно только то, что есть в плане и не `problem`/`same`.

Перед первым изменением OC сохраняет текущие настройки в `<data>/backups/oc-settings-<время>.json` (последние 10); не удалось сохранить — ничего не меняется.
Секции применяются по порядку, зависимости раньше зависимых; ошибка одной секции не откатывает остальные и попадает в отчёт.

## Секции
Интерфейс секции — `internal/bundle.Section` (`Export`, `Plan`, `Apply`). Секции подключаются в `Server.settingsSections` по мере готовности: layouts + sources (#192), deck (#193),
plugins (#194), store и app (#195).
