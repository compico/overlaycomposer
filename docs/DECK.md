# Deck: панель управления для старых устройств

Страница `/deck` — крупные плитки в духе начального экрана Windows 8 для iPad 3 / Safari 9 и подобных: одно касание — действие.
Страницу целиком собирает сервер (`internal/deck`, `html/template`): плитки, цвета и подписи уже в HTML, клиентский код — ES5 без зависимостей.

## Открыть
1. Сопряжение устройства — как для редактора (`/pair`). Если открыть `/deck` без токена, после ввода кода откроется именно панель.
2. Проба совместимости: `/deck/probe` показывает, что умеет браузер (WebSocket, Promise, flexbox…) и открывается ли тестовый WebSocket к OC.

## Раскладка
- Клетка квадратная. Рядов всегда 4: высота экрана делится на ряды (плюс строка заголовка группы), поэтому поворот устройства меняет только
  размер клетки и число видимых колонок, а не раскладку. Дальше — прокрутка вправо (палец, `-webkit-overflow-scrolling`).
- Плитки собраны в **группы** с заголовками; группы идут слева направо. Ширина группы — по самой правой плитке (до 16 колонок).
- Размеры плиток (ширина × высота в клетках): **1×1**, **2×1** (широкая: названия сцен и треков), **3×1** (очень широкая) и **2×3** (крупная, для редких случаев).
- До 16 групп, до 200 плиток. Страниц нет: их заменяют группы и прокрутка.
- Пока раскладка не сохранена, показывается раскладка по умолчанию: плитка 2×1 на каждую сцену OBS (в порядке OBS), столбцами по 4, группами по 8 сцен.
- Хранится в таблице `settings` (`deck_layout`, JSON), ревизия `rev` растёт при каждом сохранении; устройство сравнивает её со своей и
  перерисовывается (положение прокрутки сохраняется). Сброс на раскладку по умолчанию не откатывает счётчик (`deck_rev`).

Плитка: `id` (уникален во всей раскладке), `x y w h` (клетки внутри группы), `label` (до 40 символов), `color` (имя из палитры Metro, не
произвольный CSS), `icon` (из фиксированного набора символов), `confirm` (опасное: выполняется вторым касанием), `action`.
Действия:
- `scene` — сменить сцену OBS (сцена должна быть в списке OBS);
- `mute` — переключить mute аудиоисточника из общего микшера OBS: `{"type":"mute","input":"Mic/Aux"}`. Имя должно быть в списке источников OBS (сервер запоминает их при подключении и следит за событиями), иначе нажатие даёт 404. Плитка подсвечена, пока источник заглушён. В редакторе: «What it does» → «Mute an audio source»; без OBS имя вводится вручную.
- `folder` — папка со сценами: `{"type":"folder","scenes":["Game","Chat"]}` (1–8 сцен без повторов). Нажатие открывает на панели список сцен, выбор переключает сцену и закрывает список. Плитка подсвечена, когда активна одна из её сцен, и показывает её название. `confirm` для папки не используется. В редакторе: «What it does» → «Folder of scenes», сцены отмечаются флажками (порядок — как отметили; без OBS — по имени в строке).
- `plugin` — действие wasm-плагина: `{"type":"plugin","plugin":"music","pluginAction":"toggle"}`. Плагин объявляет такие действия в `Meta.Actions`
  (см. WASM_PLUGINS.md), редактор предлагает их списком «What it does». Маршрут и тело запроса сервер берёт из объявления плагина, а не от устройства.
  Плагина или действия может не быть (удалён, не установлен): раскладка остаётся валидной, а нажатие отвечает 404; плагин не запущен — 503;
  плагин не ответил или упал — 502; плагин отказал (например, «ничего не играет») — 409 с его короткой фразой на плитке.

```json
{"rev": 1, "groups": [
  {"id": "scenes", "name": "Scenes", "tiles": [
    {"id": "game", "x": 0, "y": 0, "w": 2, "h": 1, "label": "Game", "color": "blue", "action": {"type": "scene", "scene": "Game"}}
  ]}
]}
```

## Микшер
Группа раскладки `{"id":"mix","name":"Mixer","kind":"mixer","cols":8,"tiles":[]}`: готовый микшер активных источников звука OBS, без настройки (в раскладке одна, плиток в ней нет, `cols` 4–16). Для каждого источника: имя и громкость в дБ, горизонтальный фейдер (ход как у фейдера OBS: первая половина точная, край — −inf, выше 0 дБ не поднимается), mute, прослушивание (вкл/выкл; режим «только наушники», выставленный в OBS, показывается жёлтым) и шкала уровня с зонами, peak hold и индикатором клиппинга (> −1 дБ). Состав меняется вместе со сценой: OBS присылает уровни только активных источников. В редакторе: «+ Mixer».

Как это устроено: устройство по WebSocket панели шлёт `{"t":"mixer","on":true}` — сервер включает в OBS подписку на уровни (`InputVolumeMeters`, около 20 кадров/с) и шлёт `{"t":"mixer","inputs":[…]}`; в фоне вкладки подписка снимается, когда соединений не остаётся — выключается и в OBS. Команды — по тому же соединению: `{"t":"mx","a":"toggle|monitor","n":"имя"}`, `{"t":"mx","a":"vol","n":"имя","db":-12.5}`. Сервер принимает их, только пока в сохранённой раскладке есть группа-микшер и только для активных источников; не чаще ~60 в секунду с соединения. Без WebSocket (опрос) микшер не работает. Страница на ES5, полоски рисуются через `transform`: проверено на старом iPad.

## API
| метод | путь | |
|---|---|---|
| GET | `/deck` | страница (SSR) |
| GET | `/api/deck/state` | `{rev, online, scene, on}` — запасной вариант: опрос раз в 2 с, если WebSocket недоступен; `on` — id подсвеченных плиток, `text` — тексты плиток плагинов (id → строки) |
| GET (WS) | `/api/deck/ws` | сервер сам шлёт `{"t":"state",rev,online,scene,on,text}` при подключении и при каждом изменении (проверка раз в 0,5 с, пока кто-то подключён; сохранение раскладки — сразу). Тот же origin, до 16 соединений, ping раз в 20 с. CSP страницы разрешает `ws://`/`wss://` на её адрес. Клиент при обрыве переходит на опрос и переподключается с нарастающей паузой |
| POST | `/api/deck/press` | `{tile, confirm}` — нажатие (для папки ещё `scene` — выбранная сцена из её списка); нужен заголовок `X-Overlay-Composer: 1` |
| GET | `/api/deck/layout` | раскладка + сцены, `pluginActions` (действия установленных плагинов), `palette` (имя→цвет), `icons` (имя→символ), сетка (ряды, размеры плиток) для редактора |
| PUT | `/api/deck/layout` | сохранить; `rev` в теле должен совпасть с текущим, иначе 409 |
| DELETE | `/api/deck/layout` | вернуть раскладку по умолчанию |

## Безопасность
- Клиент присылает только `id` плитки. Действие берётся из сохранённой раскладки на сервере: устройство не может вызвать произвольный маршрут
  или сцену. Неизвестная плитка — 404; сцены, которой нет в OBS, — 404.
- Опасные плитки (`confirm`) сервер выполняет только с `confirm:true` (второе касание), иначе 409.
- Нажатия ограничены по частоте (всплеск 16, затем 8/с).
- Доступ с других устройств — по токену сопряжения (`authGuard`); `POST/PUT/DELETE` требуют заголовок приложения (защита от чужих страниц).
- Страница отдаётся с CSP: только свои inline-стили/скрипт и запросы на тот же адрес; метки и сцены экранирует `html/template`.

## Редактор

Кнопка **▦ Deck** в шапке редактора. Группы показаны полосой слева направо, как на планшете; плитки перетаскиваются мышью (в том числе
между группами), «+ Tile» добавляет плитку выбранного размера на первое свободное место (сцена — первая ещё не использованная).
Свойства выбранной плитки: подпись, сцена, цвет, значок, размер (только те, что помещаются), «confirm». Сохранение — кнопкой Save;
если раскладку тем временем изменили в другом месте (409), предлагается перечитать. При закрытии с несохранённым спрашивает.
Код: `web/client/editor/features/deck/` (`ops.ts` — чистые операции, `model.ts` — состояние и API, `view.ts` — DOM).
